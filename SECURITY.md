# Security policy

Pilothouse runs your coding agents in real terminals and lets paired phones and browsers act on them, so security reports matter. How it works: [usepilothouse.com/security.html](https://usepilothouse.com/security.html).

**Please don't open a public issue for a security problem.** Report it privately, either with GitHub's **Report a vulnerability** button (Security tab) or by email to **aemresrbyk@gmail.com**, with:

- what you found and how to reproduce it,
- the Pilothouse version, and where it happens: desktop app (macOS / Windows / Linux), Pilothouse server, the iPhone app, the web app at usepilothouse.com/app, or the relay.

You'll get a reply within a few days. Fixes ship as a new release; the desktop app updates itself.

Only the latest release is supported.
