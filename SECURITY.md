# Security policy

Pilothouse runs your coding agents in real terminals on your Mac, so security
reports matter.

**Please don't open a public issue for a security problem.** Email
**aemresrbyk@gmail.com** with:

- what you found and how to reproduce it,
- the Pilothouse version and macOS version.

You'll get a reply within a few days. Fixes ship as a new release; the app
updates itself.

Only the latest release is supported.
